静态站点 · 无框架 · 无构建

把想法上线，
别把周末搭进去。

一个 HTML 文件、一份样式表、一小段脚本。没有 node_modules， 没有构建流水线，双击就能看，推送就能发。

看看它有什么 它为什么这么小

三件小事，做到位

⚡

打开就是最后形态

浏览器直接渲染你写的 HTML，没有打包、没有热更新守护进程，也没有"为什么线上和我本地不一样"。

🪶

体积小到可以忽略

整站连同样式和脚本不过几十 KB，首屏不需要等待任何第三方脚本下载。

🧳

放到哪都能跑

GitHub Pages、Netlify、一台装了 nginx 的旧机器、甚至 U 盘——只要能发文件，它就能用。

关于这个项目

这是一个起点，而不是成品。它故意保持朴素：没有依赖，没有配置， 没有需要定期升级的东西。你可以直接改文案、换配色，或者把它当作 更大项目的静态外壳。

所有内容都在版本控制里，提交历史就是改动记录。想回退？git revert 就好。
